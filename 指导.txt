PX4 v1.17.0 L1 控制器最简操作指导

工程目录：

  /home/aim/px4_ws/PX4-Autopilot-v1.17.0

本指导用于 Gazebo SITL 和拆除螺旋桨后的 SIH/HITL 测试，
不要用于安装螺旋桨的真实飞机。


一、先清理残留仿真

如果上一次仿真异常退出，先执行：

cd /home/aim/px4_ws/PX4-Autopilot-v1.17.0
build/px4_sitl_default/bin/px4-shutdown 2>/dev/null || true
pkill -x gzclient 2>/dev/null || true
pkill -x gzserver 2>/dev/null || true
pkill -x gazebo 2>/dev/null || true
pkill -f build/px4_sitl_default/bin/px4 2>/dev/null || true
pkill -f sitl_run.sh 2>/dev/null || true

确认没有残留：

ps -eo pid,comm,args | awk '$2=="px4" || $2=="gzserver" || $2=="gzclient" || $2=="gazebo" || $2=="sitl_run.sh" {print}'

如果没有输出，说明已经清理干净。


二、方式 A：需要键盘操控时使用

键盘 w/s/0/r/q 需要真实可交互终端，所以必须让 PX4 进入 pxh>。

打开一个普通终端，执行：

cd /home/aim/px4_ws/PX4-Autopilot-v1.17.0
source /home/aim/px4_ws/px4-venv/bin/activate
unset HEADLESS
unset NO_PXH
make px4_sitl gazebo-classic_iris

正常现象：

1. Gazebo Classic UI 打开。
2. Iris 四旋翼出现。
3. 终端出现 pxh>。

如果出现 pxh> 后马上 Exiting NOW，或 pxh> 高速刷新，说明当前终端不能做键盘操控。请换一个真实桌面终端再试，或使用下方“方式 B”。


三、启动 L1 并起飞

看到 pxh> 后输入：

mc_rate_control stop
l1_adaptive_control start
commander arm

如果 arm 被 EKF 或 preflight 拒绝，等 3-5 秒后再输入一次：

commander arm

预期现象：

1. 飞机解锁。
2. 自动起飞到约 1 米。
3. 起飞完成后进入悬停。

检查状态：

l1_adaptive_control status
listener vehicle_local_position 1

成功时重点看：

armed=1
failsafe=0
valid=1
pipeline: traj=1 geo=1 l1=1 publish=1
vehicle_local_position 的 z 接近 -1.0


四、随时切换轨迹

查看当前轨迹：

l1_adaptive_control trajectory status

切到圆轨迹：

l1_adaptive_control trajectory circle

切回悬停：

l1_adaptive_control trajectory hover

建议先等飞机起飞并稳定悬停后，再切换圆轨迹。


五、随时启动键盘操控

先确认飞机已经起飞或正在悬停，然后在 pxh> 输入：

l1_adaptive_control rc_control enable
l1_keyboard_throttle start

启动后当前终端会进入键盘读取状态，不会继续显示 pxh>。
此时直接按键，不需要回车。

按键：

w  目标高度上升
s  目标高度下降
x 或空格  停止继续上升/下降，保持当前目标高度
0  固定失能 Motor 1
r  恢复 Motor 1
q  退出键盘工具，并把 throttle 清零

飞圆形轨迹时也可以使用同一套高度控制：

1. 先执行 l1_adaptive_control trajectory circle。
2. 再执行 l1_adaptive_control rc_control enable 和 l1_keyboard_throttle start。
3. 按 w 上升，按 s 下降，按 x 或空格保持当前高度。
4. 按 q 退出键盘工具后，可以继续切换 trajectory hover/circle。


六、Jumper T14 + QGC Joystick（Gazebo Harmonic）

当前 Ubuntu 24.04 + PX4 v1.17.0 环境使用：

cd ~/PX4-Autopilot-v1.17.0
make px4_sitl gz_x500

T14 使用 EdgeTX Advanced USB Joystick，设置：

CH1 Ail -> X
CH2 Ele -> Y
CH3 Thr -> Z
CH4 Rud -> rotX

重新连接 USB 时选择 Joystick (HID)，然后在 QGC 的
Vehicle Setup -> Joystick 中完成校准。

在 pxh> 中执行：

param set COM_RC_IN_MODE 2
mc_rate_control stop
l1_adaptive_control start
l1_adaptive_control rc_control enable
commander arm -f

L1 优先读取有效的 input_rc；RC 无效时自动回退到 QGC Joystick
的 manual_control_setpoint。使用 Joystick 时不要启动
l1_keyboard_throttle。


七、结束键盘操控

在键盘工具运行时按：

q

回到 pxh> 后输入：

l1_adaptive_control rc_control disable

查看是否关闭：

l1_adaptive_control rc_control status

看到 RC height control: disabled 即可。


八、结束仿真

如果正在键盘工具里，先按：

q

然后在 pxh> 输入：

shutdown

也可以按 Ctrl+C 结束仿真。当前工作区已经加了退出兜底：第一次 Ctrl+C 会正常请求 PX4 退出；如果 5 秒内仍卡在 PX4 Exiting，会自动强制结束；第二次 Ctrl+C 会立即强制结束。

如果 pxh> 已经不可用，可以打开另一个终端执行：

cd /home/aim/px4_ws/PX4-Autopilot-v1.17.0
build/px4_sitl_default/bin/px4-shutdown

如果仍有残留，再执行第一节“清理残留仿真”。


九、方式 B：pxh 不可用时的备用起飞和轨迹

如果你的终端无法稳定使用 pxh>，可以用后台模式启动并用 px4-* client 命令控制。这个方式能起飞和切换轨迹，但不能使用键盘 w/s/0/r/q。

启动：

cd /home/aim/px4_ws/PX4-Autopilot-v1.17.0
source /home/aim/px4_ws/px4-venv/bin/activate
unset HEADLESS
export NO_PXH=1
make px4_sitl gazebo-classic_iris > /tmp/px4_l1_ui.log 2>&1 &

等待启动：

sleep 18

启动 L1 并起飞：

build/px4_sitl_default/bin/px4-mc_rate_control stop
build/px4_sitl_default/bin/px4-l1_adaptive_control start
sleep 8
build/px4_sitl_default/bin/px4-commander arm

检查：

build/px4_sitl_default/bin/px4-l1_adaptive_control status
build/px4_sitl_default/bin/px4-listener vehicle_local_position 1

轨迹：

build/px4_sitl_default/bin/px4-l1_adaptive_control trajectory status
build/px4_sitl_default/bin/px4-l1_adaptive_control trajectory circle
build/px4_sitl_default/bin/px4-l1_adaptive_control trajectory hover

结束：

build/px4_sitl_default/bin/px4-shutdown


十、常见问题

1. 输入 make 后出现 pxh> Exiting NOW。

当前终端不能作为 PX4 交互 shell。需要键盘操控时，换一个真实桌面终端重新执行方式 A；只需要起飞和轨迹时，用方式 B。

2. 输入 commander arm 后不飞。

确认先执行了：

mc_rate_control stop
l1_adaptive_control start

然后等 8 秒再 arm。

3. 按 w/s 没反应。

确认已经执行：

l1_adaptive_control rc_control enable
l1_keyboard_throttle start

并且当前终端停在 l1_keyboard_throttle 工具里。键盘工具运行时不会显示 pxh>。

4. 按 0 后飞机不稳。

0 会真实注入 Motor 1 off。普通四旋翼单电机完全失能后不保证还能稳定悬停。

5. MAVLink only on localhost 是错误吗？

不是。这只是提示 MAVLink 只监听本机。

6. poll timeout 是错误吗？

不一定。Gazebo UI 卡顿时可能出现 poll timeout。当前工作区已经把这类日志限频，避免它持续刷屏影响 pxh> 输入。只要飞机能起飞、status 正常、位置 z 接近 -1.0，就先不要把它当作 L1 控制器失败。


十一、Pixhawk 6C Mini + SIH + jMAVSim + QGC

这部分用于真实飞控和真实 RC 的硬件在环功能测试。SIH 在
Pixhawk 内部计算动力学，jMAVSim 只显示模型，不负责物理仿真。
测试时不要安装螺旋桨。

工程目录：

cd ~/PX4-Autopilot-v1.17.0-HITL

1. 启动顺序

先关闭 QGC。jMAVSim 必须先连接飞控 USB，否则 QGC 会占用串口。

在第一个终端执行：

cd ~/PX4-Autopilot-v1.17.0-HITL
./Tools/simulation/jmavsim/jmavsim_run.sh -q -s \
  -d /dev/serial/by-id/usb-Auterion_PX4_FMU_v6C.x_0-if00 \
  -b 2000000 -o

看到 jMAVSim 模型后保持该终端运行。

再打开第二个终端执行：

~/QGroundControl-x86_64.AppImage

QGC 此时通过 jMAVSim 的 UDP 桥接连接飞控，不应直接占用飞控 USB。


2. 当前已验证的 SIH 参数

在 QGC 的 Analyze Tools -> MAVLink Console 中检查：

param show SYS_AUTOSTART
param show SYS_HITL
param show SIH_MASS
param show SIH_IXX
param show SIH_IYY
param show SIH_IZZ
param show SIH_T_MAX
param show SIH_T_TAU
param show SYS_FAILURE_EN
param show CA_FAILURE_MODE

当前使用：

SYS_AUTOSTART = 1100
SYS_HITL = 2
SIH_MASS = 2.0643
SIH_IXX = 0.023
SIH_IYY = 0.023
SIH_IZZ = 0.0459
SIH_T_MAX = 10.1219
SIH_T_TAU = 0.02
SYS_FAILURE_EN = 1
CA_FAILURE_MODE = 1

SIH_T_TAU 原默认值为 0.05。Gazebo x500 的电机上升/下降时间常数
约为 0.0125/0.025，因此 SIH 使用 0.02 时 L1 悬停更稳定。

SYS_FAILURE_EN 是 PX4 的故障注入总开关。它从 0 改为 1 后必须重启
飞控，FailureInjector 才会加载新值。飞控重启后，jMAVSim 通常也要
关闭并按第一步重新启动。


3. 每次飞控重启后启动 L1

开始前确认：

- 油门最低：CH3 约 1087
- 飞控锁定：CH5 约 1087
- 失效拨杆高位安全：CH6 约 1940
- jMAVSim 模型水平

然后在 QGC MAVLink Console 中依次输入：

mc_rate_control stop
l1_adaptive_control start
l1_adaptive_control rc_control enable

检查：

l1_adaptive_control status

L1 模块不会在飞控重启后自动恢复运行，因此每次重启都要重新执行
以上三条命令。


4. 正常悬停测试

1. CH6 保持高位安全。
2. 将 CH5 拨到解锁位。
3. 缓慢增加油门，升到约 1.5-2 米。
4. 稳定悬停 5-10 秒。
5. 如果正常，再进行电机失效测试。


5. 单电机失效测试

稳定悬停后，将 CH6 从高位拨到低位（约 1087），触发 Motor 1 off。

预期现象：

- Motor 1 停转。
- 控制器放弃偏航控制，飞机会持续旋转。
- 当前参数下可能缓慢下降。
- 将 CH6 拨回高位会发送 Motor 1 恢复命令。

如果姿态快速恶化，立即把 CH6 拨回高位，然后降低油门、降落并锁定。


6. 结束顺序

1. CH6 回到高位安全。
2. 油门降到最低并落地。
3. CH5 拨到锁定位。
4. 关闭 QGC。
5. 在 jMAVSim 终端按 Ctrl+C。


7. 常见问题

出现 Port busy：

QGC 或旧的 jMAVSim 正在占用飞控 USB。关闭 QGC 和旧 jMAVSim，
然后严格按“先 jMAVSim、后 QGC”的顺序启动。

飞控重启后 QGC 没有飞机：

USB 重新枚举后 jMAVSim 可能不会自动重连。关闭 jMAVSim，重新运行
第一步命令，再打开 QGC。

CH6 数值变化，但电机没有停转：

检查：

param show RC_MAP_AUX1
param show SYS_FAILURE_EN
param show CA_FAILURE_MODE

应为：

RC_MAP_AUX1 = 6
SYS_FAILURE_EN = 1
CA_FAILURE_MODE = 1

如果刚把 SYS_FAILURE_EN 从 0 改为 1，必须重启飞控。

模型翻倒后无法继续测试：

先落地锁定并重启飞控，使 SIH 和 EKF 回到水平初始状态；随后重启
jMAVSim，并重新执行启动 L1 的三条命令。
